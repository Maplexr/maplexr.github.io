# 需求文档

## 1. 应用概述

### 1.1 应用名称
辛瑞（v-max）个人主页（Xin Rui (v-max) Personal Homepage）

### 1.2 应用描述
一个集个人形象展示与AI数字分身互动于一体的个人主页Web应用。主页展示主人的基本身份、兴趣方向和当前专注领域，并提供数字分身问答与多模态互动区，帮助访客快速了解主人并获得AI自媒体相关建议。支持用户注册登录、跨会话聊天记录持久化与导出、语音输入与播报、多主题换肤以及中英文双语切换。

## 2. 用户与使用场景

### 2.1 目标用户
- 对AI领域感兴趣但不知如何入手的初学者或迷茫者
- 关注自媒体与AI应用的内容受众
- 潜在的商业合作伙伴或企业客户

### 2.2 核心使用场景
- 浏览个人信息：访客浏览辛瑞（v-max）的个人介绍、背景与专长领域
- 账号注册与登录：访客注册并登录个人账号，以获取完整的数字分身互动与数据持久化能力
- 数字分身互动：登录用户在聊天区通过文本或语音向数字分身提问，获取文本解答与语音播报
- 历史记录管理与导出：用户查看历史对话记录，并将聊天内容导出为文件保存
- 个性化偏好设置：用户根据使用习惯切换中英文界面与主题视觉配色

## 3. 页面结构与功能说明

### 3.1 页面结构

```
辛瑞（v-max）个人主页
├── 顶部导航栏
│   ├── 语言切换控件（中/英）
│   ├── 主题换肤控件（深色/浅色/特色主题）
│   └── 用户账号入口（登录/注册/用户状态/退出登录）
├── 个人信息展示区
│   ├── 头像展示
│   ├── 姓名与一句话介绍
│   └── 详细个人信息卡片（身份、当前专注、兴趣爱好、核心特质）
├── 数字分身互动区
│   ├── 历史对话流与视频互动展示区
│   ├── 预置推荐问题快捷按钮
│   ├── 聊天记录导出控件
│   └── 输入控制栏（文本输入、语音输入控件、发送按钮）
└── 登录/注册弹窗
    ├── 用户注册表单（账号/邮箱、密码）
    └── 用户登录表单（账号/邮箱、密码）
```

### 3.2 功能说明

#### 3.2.1 顶部导航栏
- 语言切换：提供中文与英文切换能力，切换后全站文本（含个人介绍与数字分身预置内容）即时更新为对应语言。
- 主题换肤：提供多款主题配色（包含默认深色、浅色及其他特色配色）切换，切换后全站样式即时生效并持久化保存用户偏好。
- 用户账号入口：未登录状态展示登录/注册入口；已登录状态展示当前用户名及退出登录操作。

#### 3.2.2 登录/注册弹窗
- 用户注册：用户输入账号（或邮箱）及密码完成注册。
- 用户登录：用户输入已注册账号及密码完成登录，支持退出登录。
- 访问权限控制：未登录访客可自由浏览个人信息展示区，数字分身聊天区提示需登录后体验完整互动及记录保存功能。

#### 3.2.3 个人信息展示区
- 头像与基础信息：
  - 头像展示：使用指定图片（https://miaoda-conversation-file.cdn.bcebos.com/user-ezis6iq627eo/app-eziu2hez74zl/20261010/67e779b669df0ded18dc5d6a62fb66e2_1791626803772.jpg）。
  - 姓名展示：中文名「辛瑞（v-max）」，英文名展示「Xin Rui (v-max)」。
  - 一句话介绍：「维持薄肌和孙学思维的codex发烧年轻人」。
- 详细背景展示：
  - 身份定位：27届美术生、AI自媒体创作者。
  - 专注方向：AI自媒体探索、帮助迷茫与不敢尝试AI的人起步。
  - 兴趣标签：健身、旅游、codex、自媒体。
  - 核心特质：执行力强、深度思考未来AI趋势。

#### 3.2.4 数字分身互动区
- 预置问题快捷入口：提供3个高频推荐问题卡片，用户可点击直接发送：
  1. 如何入手AI去做自媒体？
  2. 做AI自媒体如何变现？
  3. 如何联系到辛瑞（v-max）？
- 文本互动：用户在输入框中输入自定义文本并发送，数字分身基于辛瑞（v-max）的知识背景生成并展示回答。
- 语音互动：
  - 语音输入：支持用户按住或点击录音进行语音输入，自动将语音转换为文本填入输入框。
  - 语音播报：数字分身回复消息提供语音朗读播放控件，支持将文本转为语音进行播放。
- 视频互动展示：在互动区域展示数字分身视频形象联动状态作为辅助互动形式。
- 历史记录持久化：登录用户的对话记录持久化保存至后端，刷新或重新打开页面可自动恢复历史对话。
- 聊天记录导出：支持将当前账号的历史或当前会话聊天记录导出为文件（文本或Markdown格式）下载到本地。

## 4. 业务规则与核心逻辑

### 4.1 核心业务规则
1. 视觉主题规则：默认采用深色（黑色系）主题；用户切换主题后，新主题偏好自动持久化保存，下次访问默认应用所选主题。
2. 语言切换逻辑：默认展示中文界面；切换为英文后，界面文案与数字分身问答内容对应转换为英文。
3. 数字分身知识库规则：数字分身基于预设知识库作答，核心围绕27届美术生背景、AI自媒体起步、商业变现思维及联系方式，超出认知范围的内容进行友好引导说明。
4. 数据绑定与持久化规则：聊天记录严格与当前登录用户账号绑定，用户登出后本地不残留会话信息，重新登录后拉取该账号的历史记录。
5. 权限控制规则：未登录用户进入聊天区时，限制发送操作并提示登录；登录完成后自动解锁全部互动功能。

## 5. 异常与边界情况

| 场景 | 表现与处理规则 |
| :--- | :--- |
| 未登录用户尝试提问 | 弹出登录/注册提示，引导用户完成身份验证后继续提问 |
| 空消息或静音录音发送 | 输入框无内容或未识别到有效语音时，发送按钮置灰禁用，无法提交 |
| 语音识别无权限或失败 | 提示用户检查麦克风权限或重新录入，支持退回纯文本输入模式 |
| 导出无记录对话 | 当前会话无消息时，导出按钮处于禁用状态 |
| 数字分身应答生成中 | 展示回复生成中状态，生成期间禁用重复发送控件 |
| 账号重复注册 | 提示该账号已被注册，引导用户直接登录 |

## 6. 验收标准

1. 访客能够完整查看辛瑞（v-max）的指定头像图片、姓名、一句话介绍、27届美术生身份背景及兴趣爱好等个人展示内容。
2. 用户能够完成账号注册、登录及登出流程，登录状态在页面刷新后保持有效。
3. 用户在登录状态下可发送预置问题或自定义问题，数字分身能给出符合设定背景的回答。
4. 用户可通过语音输入转换文本发送，并可对数字分身的回复进行语音播报。
5. 登录用户的历史聊天记录支持跨会话持久化保留，且支持导出为文本或Markdown文件。
6. 用户在主题切换器中切换不同主题，全站样式即时统一更新，刷新后主题偏好保持一致。
7. 用户切换中英文语言时，全站展示内容与问答交互即时更新为对应语种。
